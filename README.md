# Silicon Sprint AUC

**An open-source ASIC design workshop for taking a Wishbone-connected design from RTL to GDSII using LibreLane and the SkyWater 130nm process.**

## Overview

Silicon Sprint AUC is a hands-on educational repository for learning open-source ASIC physical design. The workshop walks through a complete implementation flow: RTL integration, synthesis, floorplanning, placement, clock tree synthesis, routing, physical verification, and final layout generation.

The main workshop exercise centers on integrating an AES-128 accelerator through a Wishbone bus wrapper, hardening it with LibreLane, and preparing it for Caravel/OpenFrame-style multi-project chip integration. The repository includes documentation, Verilog sources, LibreLane configurations, verification collateral, generated layout views, and signoff reports.

This project is intended for students, instructors, and hardware engineers who want a practical introduction to the open silicon flow without relying on proprietary EDA tools.

## What This Repository Provides

- Step-by-step workshop documentation for the full RTL-to-GDSII flow.
- Caravel-compatible wrapper collateral and example user project structure.
- LibreLane configuration files for macro and wrapper hardening.
- Reference physical views, including GDS, LEF, DEF, Liberty, SPEF, SDF, SPICE, and gate-level netlists.
- Digital verification examples for Wishbone, GPIO, logic analyzer, and cocotb-based tests.
- Signoff outputs for timing, DRC, LVS, antenna checks, and related physical verification reports.

## Flow Coverage

| Stage | Main Tools | Outcome |
| :--- | :--- | :--- |
| RTL linting and integration | Verilator, Yosys | Clean design hierarchy and bus integration |
| Synthesis | Yosys | Technology-mapped gate-level netlist |
| Floorplanning and PDN | OpenROAD | Die area, pin placement, power grid, and macro placement |
| Placement and CTS | OpenROAD | Legalized cells and synthesized clock network |
| Routing | OpenROAD, TritonRoute | Global and detailed routed layout |
| Timing closure | OpenSTA, OpenROAD | Multi-corner timing analysis and ECO repair |
| Physical signoff | Magic, KLayout, Netgen | DRC, LVS, extraction, XOR, and final layout checks |
| Tapeout preparation | LibreLane, Caravel/OpenFrame collateral | Hardened views for multi-project chip integration |

## Workshop Modules

The full workshop is maintained in the online documentation:

**Read the docs:** <https://silicon-sprint-auc.readthedocs.io/en/latest/>

| Module | Topic | Focus |
| :--- | :--- | :--- |
| 0 | Environment Setup | Nix, LibreLane, PDK setup, smoke tests, and repository preparation |
| 1 | RTL Integration and PDN | Wishbone wrapper, synthesis exploration, SDC, floorplan, and power network |
| 2 | Placement and CTS | I/O constraints, placement, clock tree synthesis, and post-CTS repair |
| 3 | Routing | Global routing, antenna repair, detailed routing, and route inspection |
| 4 | Physical Signoff | Fill insertion, extraction, STA, IR drop, DRC, LVS, XOR, and final GDSII |
| 5 | Caravel Wrapper Integration | Macro-first, top-level, and flattened wrapper hardening strategies |
| 6 | OpenFrame Tape-Out Preparation | Multi-project chip integration contracts, slot planning, and final hardening |

## Getting Started

1. Clone this repository:

   ```console
   git clone https://github.com/basemhesham/Silicon-Sprint-AUC.git
   cd Silicon-Sprint-AUC
   ```

2. If you are following the AES workshop flow, clone the AES RTL source used by the modules:

   ```console
   git clone https://github.com/secworks/aes.git ~/secworks_aes
   ```

3. Follow Module 0 in the documentation to install Nix, enter the LibreLane environment, fetch the SkyWater 130nm PDK, and run the initial toolchain smoke test:

   <https://silicon-sprint-auc.readthedocs.io/en/latest/MODULE0.html>

The ASIC toolchain is designed for Linux, WSL2, or macOS environments. Windows users should follow the WSL2 setup path described in the documentation.

## Generated Artifacts

The repository includes reference output views from the hardening flow. These files are useful for inspection, comparison, and wrapper integration:

- `gds/`: stream-out layout databases.
- `lef/`: macro abstracts for integration.
- `def/`: placed and routed design exchange format files.
- `verilog/gl/`: gate-level netlists.
- `spef/`: parasitic extraction files, including multi-corner SPEF.
- `lib/`: Liberty timing models.
- `signoff/`: final metrics, timing summaries, DRC/LVS logs, and signoff reports.

Before using any collateral for a new tapeout or shuttle submission, re-run the flow and signoff checks in your own environment.
